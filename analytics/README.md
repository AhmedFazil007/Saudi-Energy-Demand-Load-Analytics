# Ahmed Fazil — Business Analytics Portfolio

A minimal, free, static website with six internal case studies. Each case study includes findings, business relevance, suggested actions, KPIs and a clear synthetic-data disclaimer.

## Online URL
https://ahmedfazil007.github.io/Saudi-Energy-Demand-Load-Analytics/analytics/

## Features
- No paid hosting, npm, framework or backend required
- Six case studies open inside the website using the `?project=` URL parameter
- Responsive design, subtle motion and reduced-motion support
- Email via mailto plus a visible address and a copy button
- LinkedIn and GitHub links open separately
- Synthetic-data disclosures; recommendations are not claimed as achieved results

## Edit
The website is located in `analytics/` in this repository. Edit `app.js` for case-study copy, `style.css` for design and `index.html` for page metadata.
